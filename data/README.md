# Data

This project uses the InfraredSolarModules dataset for thermal-image classification of photovoltaic modules.

## Dataset

The dataset contains thermal images of PV modules labelled by condition, including normal modules and several fault categories.

The full dataset is not stored in this GitHub repository because it contains a large number of image files.

## Download

Download the dataset from the original source used by the project team.

https://github.com/RaptorMaps/InfraredSolarModules
